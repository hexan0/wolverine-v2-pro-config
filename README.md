# wolverine-v2-pro-config
**非公式ツールです。**Razer Wolverine V2 Proというコントローラーの設定をWindows PCから行えるツールです。

Razer社のWolverine V2 ProというコントローラーはPS5/PCで使用可能なコントローラーですが、追加ボタンの割り当てやデッドゾーンの設定はAndroidまたはiOSアプリからしか行うことができません。
これをWindows PCから設定可能にしたのがこのツールです。
